 Análisis sobre las ventas de coches en 2022 - 2023

Casos de uso y aplicación de los datos:

Los datos presentados en este proyecto se pueden utilizar para evaluar tendencias generales y variaciones regionales en las ventas de automóviles por fabricante.
El objetivo es poder investigar posibles patrones estacionales que pueda haber en las ventas de automóviles así como poder pronosticar tendencias del mercado.

Estructura del proyecto:

Este proyecto se realiza sobre la base de datos obtenida en la web https://www.kaggle.com/datasets. Esta base de datos consta únicamente de un archivo CSV con los datos sin procesar.

Datos: Archivo CSV en crudo y sin procesar.

Dentro del archivo nos encontramos con los datos diferenciados en las siguientes columnas:

1- Car_id para identificar las ventas, con datos tipo cadena de texto.

2- Date para indicar las fechas de venta, con datos tipo fecha.

3- Customer Name identificando los nombres de los clientes, con datos tipo texto.

4- Gender identifica el género de los clientes, con datos tipo texto.

5- Annual income identifica la renta anual de los clientes, con datos tipo numérico.

6- Dealer name, identifica el nombre del concesionario vendedor, con datos tipo texto.

7- Company identifica la compañías vendedoras, con datos tipo texto.

8- Model identifica los modelos de los coches, con datos tipo texto.

9- Engine identifica los tipos de motor de los coches, con datos tipo texto.

10- Transmission identifica las transmisiones de los coches, con datos tipo texto.

11- Color identifica el color de los coches, con datos tipo texto.

12- Pice identifica el precio de venta, con datos tipo numérico.

13- Dealer Nº identifica el número del vendedor, con datos tipo numerico.

14- Body Style identifica la carrocería de los coches, con datos tipo texto.

15- Phone identifica el teéfono de los vendedores, con datos tipo numérico.

16- Dealer Region identifica las regiones de ventra estudiadas, con datos tipo texto.


Análisis: Análisis de los datos en tablas dinámicas individuales.

Incluyo dentro del archivo el análisis de los datos con varias tablas individuales para identificar los más relevantes.

Resultados: Presentación de Resultados mediante Dashboard.

En el Dashboard se muestran los cálculos más relevantes obtenidos con los datos originales.

Readme: Breve descipción del proyecto.

Resultados y Conclusiones:

- Se aprecia un incremento en las ventas en el año 2023 con respecto al 2022.

- En ambos años las ventas se incrementan a partir del segundo trimestre.

- Las marcas más vendidas corresponden a fabricantes americanos.
